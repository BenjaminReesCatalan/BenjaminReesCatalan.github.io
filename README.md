## 🛠️ Stack

- **Astro** — Generador de sitios estáticos
- **HTML / CSS** — Estructura y estilos
- **Node.js** — Entorno de ejecución

## 🚀 Desarrollo local

```sh
npm install        # instala dependencias
npm run dev        # servidor local en localhost:4321
npm run build      # compila el sitio de producción a ./dist/
npm run preview    # previsualiza el build local
```

## 📦 Publicación (GitHub Pages)

El sitio se publica automáticamente en GitHub Pages mediante **GitHub Actions**. Cada `push` a la rama `main` dispara el flujo `.github/workflows/deploy.yml`, que compila el proyecto y despliega el resultado.
